Overview

Computational Modelling of Reversible and Multi-Step Chemical Reactions

Project Overview

This project uses Python simulations to investigate how concentrations of both reactants and products change over time in chemical reactions. Instead of solving equations by hand, I built a mathematical model that simulates this.

This project begins with a simple reversible reaction (A ⇌ B) and then is extended to include a two step reaction mechanism including both a reversible and irreversible reaction (A ⇌ B → C). As an extension, the code was further modified to include temperature effects on reaction rates using the Arrhenius equation.

What this project covers

  • Simple reversible reaction model (A ⇌ B)
  • Two step reaction model (A ⇌ B → C)
  • Numerical simulation using Python
  • Graphical analysis of results
  • (EXTENSION) Temperature effects on reaction rates using the Arrhenius equation

Skills demonstrated

  • Python (Numpy and Matplotlib)
  • Mathematical modelling
  • Data analysis and interpretation of graphs
  • Application of chemical kinetics and equilibrium concepts
